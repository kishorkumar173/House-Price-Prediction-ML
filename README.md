# 🏠 House Price Prediction using Machine Learning

## 📌 Overview

This project predicts house prices using regression models based on real-world housing data.

## 🎯 Problem

Manual pricing is inaccurate. This project uses machine learning to predict house prices.

## ⚙️ Tech Stack

* Python
* Pandas, NumPy
* Scikit-learn
* Matplotlib, Seaborn

## 📊 Models Used

* Linear Regression
* Random Forest Regressor

## 📈 Results

Random Forest performed better with higher accuracy.

## 📂 Dataset

Kaggle House Prices Dataset

## ▶️ How to Run

```bash
python eda.py
python main.py
```

## 📸 Outputs

* Heatmap
* Price Distribution
* Actual vs Predicted Graph
